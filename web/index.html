Estúdio V4 — prévia de narração e projeto MP4

Inclua os fatos que você conferiu na fonte. O sistema não inventa informações. Ouça a prévia e exporte o roteiro para o programa Windows montar o MP4.

A prévia usa as vozes disponíveis no seu navegador. A qualidade e os direitos comerciais variam conforme o serviço. A gravação de MP3 é feita no Estúdio Windows com áudio próprio ou autorizado.
Produção de MP4: baixe o roteiro e abra no programa Windows ABRIR_ESTUDIO_V4.bat. Para publicar, aprove a narração e utilize imagens e áudio com direitos de uso.
